2 · 构造算法

Damm32 拟群定义在有限域 GF(2⁵) 上，不可约多项式 p(t) = t⁵ + t + 1（系数 0x23）：
  T[x][y] = 2 · (x ⊕ y)　 （· = GF(2⁵) 乘法，2 = 域元素 t，⊕ = 域加法 = 按位异或）
该拟群是「弱全反对称拟群」（weak totally anti-symmetric quasigroup），满足 Damm 算法 检出所有单字符替换 + 所有相邻换位的充要条件：
  • 拉丁方：每行 / 每列都是 0..31 的一个排列（运算符 ⊙ 构成拟群）；
  • 主对角线全 0：T[x][x] = 0，校验位闭合；
  • 相邻换位条件：(c⊙x)⊙y = (c⊙y)⊙x ⟹ x = y（对任意 c、x≠y 不成立）。

GF(2⁵) 特征为 2：2·a = 0 ⟺ a = 0，故不存在 Z₃₂ 里那种 「a 与 a+16 互为反极点」破坏换位条件的元素对 —— 这正是 32 阶可构造而模 32 加法不可行的原因。 与 base-10 Damm 表（同为弱全反对称拟群）性质一致，并已穷举验证。
