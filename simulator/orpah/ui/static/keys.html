说明

  • 轮换不断链：轮换后旧钥进入宽限期，期内新旧钥都能验签，端侧不必与服务器同时换钥；宽限结束旧钥退役、不再受理。
  • 作废是设备级的：整机立即不可验签（失窃/报废场景），且不可逆 —— 要恢复须先「撤销恢复」再重新签发。
  • 本页只管服务器侧该持有的东西（ES256 公钥 + 降级 HS256 对称密钥），私钥不入库；真实设备私钥永不出安全元件。
  • 「终端更新到当前代」会真的让演示终端改用新钥 —— 配合下面的代次表，可以完整看到「轮换 → 旧钥仍可用 → 退役 → 被拒 → 更新 → 恢复」。
