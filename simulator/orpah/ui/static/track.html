1 · 模拟参数

RSSI ↔ 距离换算参数（模拟 / 真实两种模式共用）。

2 · 路由器测点（无人机悬停 / 固定 AP）

#x (m)y (m)

测点坐标即路由器/无人机的悬停位置；客户端在其覆盖范围内移动，每个测点持续测 RSSI。

2 · 定位站位（无人机悬停测点）

#名称x (m)y (m) 观测窗口观测 RSSI 距离残差

打点 = 此刻无人机在该站位（自动收尾上一个站位的窗口）；窗口内所有 report 的 RSSI 取中位数作为该站位观测。「绑定」把最新一条 report 的 RSSI 直接指派给该站位。至少 2 个站位有观测才能定位。

蓝方块=站位、蓝圈=该站位的距离环、红叉=定位估计、灰点=无观测站位。坐标与上方 A/n 换算共用。

残差 = 测量距离 − 估计点到该站位的距离；RMS 越小越可信。GDOP 反映站位几何（越小越好；站位数不足、近共线或都在同一侧时 GDOP 会很大甚至无解，此时估计点不可信）。
