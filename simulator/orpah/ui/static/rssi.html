1 · 路径损耗模型

距离估算：d = 10^((A − RSSI) / (10·n))；RSSI 越小（越负）距离越远。 n=2 自由空间、2.5–4 户外/遮挡；HaLow 900MHz 户外通常 2.5–3。

2 · 测点（路由器 / 无人机悬停点）

#x (m)y (m)RSSI (dBm)

每个测点 = 无人机在某位置悬停测得该客户端的 RSSI（可手动改，或「仿真」按真实位置 + 噪声反推）。 2 个测点 → 两圆交点（二义）；3 个测点 → 唯一交点；≥4 → 最小二乘拟合。

3 · 定位结果

蓝方块=测点（标注 x,y）、橙圈=按 RSSI 估算的距离圆、绿叉=真实位置、红叉=定位结果。
