# Orpah Demo 路线图 / 待办清单

> 按「Orpah 协议目标 + 物联网演示系统」两条线梳理的缺口清单。
> 记录于 2026-09-11。逐步实现，优先级 P0 > P1 > P2。
> 完整上下文见会话记录与 `/memories/orpah-demo-roadmap.md`。

## 一、设备与身份侧（最像「产品」的缺口）

- [ ] **设备清册/注册**：客户端台账——SN、所属组织、CC、绑定人/对象、状态（启用/停用/丢失/报废）、首次入网时间、最近见时间。
- [ ] **密钥/证书生命周期**：密钥生成→分发→轮换→吊销→退役闭环；ES256 公钥、HMAC 密钥与 SN 绑定；作废机制（CRL/OCSP 思路）。
- [ ] **多算法策略与降级**：按设备安全等级自动选 alg；私钥不可用自动降级并告警。
- [ ] **无源/低功耗客户端建模**：无源唤醒周期、能量采集状态、上报间隔等客户端画像。

## 二、定位侧（track 已模拟，离真用还差）

- [ ] **真数据接入而非纯模拟**：多 router/无人机站位真实 report 聚合 → 按 sn+时间窗定位的后端管线（补 `router_id`/`router_pos`）。
- [ ] **定位质量量化**：GDOP/PDOP 显示、加权最小二乘（当前 trilaterate 是普通 LS）、误差椭圆/置信半径、按噪声 σ 滑动平均 + 卡尔曼平滑。
- [ ] **单/双/三点策略自动化**：自动判定可用测点数 + 几何共线检测，不满足自动提示补站位。
- [ ] **离线地图与野外包**：PMTiles/区域离线包切换、经纬度基点导入、轨迹导出 GPX/GeoJSON。

## 三、安全事件与运维侧

- [ ] **审计日志**：走失标记、撤销、重放、超窗、签名验签失败的持久化审计（谁/何时/哪个 SN/操作前后状态/结果），出事可回溯。
- [ ] **告警与通知**：RSSI 突变、长未上报、校验位连续失败、签名失败率超阈、走失超时 → 规则引擎 + 通知（页面红点/Webhook/邮件；演示可用 SSE 弹窗）。
- [ ] **回放**：按时间段回放报文流 + 定位轨迹 + 安全事件。
- [ ] **重放/篡改自动化测试台**：批量用例（黄金样本、边界 SN、过期 nonce、错 CC）一键跑并出报告。

## 四、传输与真机适配

- [ ] **Wi-Fi 抓包 → ORPAH 报文解析** 与 **HaLow/UDP 模拟器**双源对照；无认证空口防 spoof 演示（结合 Damm32 + 签名）。
- [ ] **多租户/多组织**：SN 按组织隔离、角色权限（看客/运维/管理员）。

## 五、可观测与交付物

- [ ] **指标面板**：校验失败率、签名算法分布、平均 RSSI、定位误差 CDF、走失处置时长。
- [ ] **配置中心**：路径损耗 A/n 校准值、各 router 坐标、锚点库、基图参数、SSE/API 地址外置。
- [ ] **文档/导览**：协议版本↔页面功能映射、黄金样本一键自检、demo 剧本（入网→移动→走失→撤销→定位）。

## 优先级

| 级别 | 项目 |
|------|------|
| **P0** | 设备清册 + SN 状态、真实 report 聚合定位（补 `router_id`/`router_pos`）、审计日志、告警红点 |
| **P1** | 密钥生命周期/吊销、GDOP + 加权 LS + 误差椭圆、回放、离线地图 |
| **P2** | 多租户权限、Wi-Fi 抓包对照、无源能耗模型、批量合规测试用例 |
