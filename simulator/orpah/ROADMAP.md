# Orpah Demo 路线图 / 待办清单

> 按「Orpah 协议目标 + 物联网演示系统」两条线梳理的缺口清单。
> 记录于 2026-09-11。逐步实现，优先级 P0 > P1 > P2。
> 2026-09-11 补充：走失案件闭环、一个走失者多客户端、隐私/时钟、无认证防 spoof 优先级上调。
> 完整上下文见 `/memories/orpah-demo-roadmap.md`。

## 一、设备与身份侧（最像「产品」的缺口）

- [x] **设备清册/注册**：客户端台账——SN、所属组织、CC、**绑定走失者/对象（一对多：一个走失者可挂多个客户端，如项链/鞋/眼镜）**、状态（启用/停用/丢失/报废）、首次入网时间、最近见时间。（`registry.py` + `registry.html`，2026-09-11 完成）
- [ ] **密钥/证书生命周期**：密钥生成→分发→轮换→吊销→退役闭环；ES256 公钥、HMAC 密钥与 SN 绑定；作废机制（CRL/OCSP 思路）。
- [ ] **多算法策略与降级**：按设备安全等级自动选 alg；私钥不可用/能量不足自动降级并告警。
- [ ] **无源/低功耗客户端建模（协议约束，非仅画像）**：无源唤醒周期、能量采集状态、上报间隔——能量决定上报频率与 alg 降级；demo 加「能量轴」。

## 二、定位侧（track 已模拟，离真用还差）

- [~] **真数据接入而非纯模拟（拆两阶段）**：阶段一——**单台无人机多点悬停**真实 report 聚合；阶段二——**多路由器并发**（补 `router_id`/`router_pos`，改 router/server 架构）。前后端统一数据模型/API，避免模拟与真实两套逻辑。
  - 已完成（2026-09-11）：前后端统一数据模型/API（`/api/ts/query`，契约见 `API.md`）；`track.html` 新增「真实上报（IoTDB 时序）」模式，直读 IoTDB 真实 RSSI 时序 + A/n 距离换算，模拟模式保留。
  - **阶段一已完成（2026-09-11）**：补上了「这个 RSSI 是在哪个**已知坐标**测到的」这一维 ——
    `stations.py` + `/api/stations`（契约见 `API.md` §7）+ `track.html` 真实模式的「定位站位」面板。
    观测两条路、写同一张表：**时间窗**（「打点」实时生成，或悬停计划 JSON 预置 `t0/t1`；
    窗内所有 report 取 RSSI 中位数）与**手动绑定**（把最新一条 report 的 RSSI 指派给某站位）。
    ≥2 个站位有观测即调用**模拟模式同一个** `trilaterate()` → 画站位 / 距离环 / 估计点。
    站位表存 SQLite（`stations` 表），重启不丢；示例悬停计划见 `stations.example.json`。
  - **阶段二未做（唯一剩余项）**：真实 `router_id` 仍是空串（`ui_server.py` 收到 report 时没传），
    多路由器并发需 router 侧各自带编号 + 坐标。当前用「悬停点」代替多站点，达到同一定位效果。
- [~] **定位质量量化**：GDOP/PDOP、加权最小二乘（权重随距离增大而减小，σ∝距离）、误差椭圆/置信半径、滑动平均 + 卡尔曼滤波。
  - 已做（2026-09-11）：**残差 RMS**（每个站位「测量 − 估计」逐条列出 + 总体 RMS 分级）、
    **GDOP**（估计点到各站位单位向量，越小越好）、**站位布局条件数**（λmax/λmin，∞ = 完全共线）
    用于「解不出来」时区分是站位几何不行还是距离环不相交。
    为何必做：恒定 RSSI 这类退化输入会让 LS 解落在「外接圆心」，看着像个正常坐标、实际无意义。
    实测：给一组由真值点反算的 RSSI → 精确解回 `(0.0, 0.0)`、RMS 0.0、GDOP 1.22。
  - 未做：加权最小二乘（σ∝距离）、误差椭圆/置信半径、滑动平均 + 卡尔曼滤波。
- [~] **单/双/三点策略自动化**：自动判定可用测点数 + 几何共线检测，不满足自动提示补站位。
  - 已做（2026-09-11）：可用测点数自动统计（真实模式「参与定位：n/t 个站位有观测」），
    不足 2 个时直接提示、不出估计点。
  - 未做：置信半径（站形条件数已能提示共线，见上）。
- [ ] **离线地图与野外包**：PMTiles/区域离线包切换、经纬度基点导入、轨迹导出 GPX/GeoJSON。
  - **授权约束（2026-09-11 核实，必须遵守）**：`tile.openstreetmap.org` 的 Tile Usage Policy **明令禁止离线**
    （"Offline use is not permitted on tile.openstreetmap.org"），也禁止预取/批量下载/建瓦片包；
    且无 SLA、可无预警封禁，policy 原文提醒「商业服务可能随时失去访问」。
    故本项**不得**基于 OSM 官方瓦片，必须自建瓦片（switch2osm，PMTiles 自建即合规）
    或改用明确允许离线的供应商。

## 三、案件闭环 + 安全事件与运维

- [x] **走失案件闭环（以人为单位，非单 SN）**：某人走失 → 标记（其名下所有设备进入走失态）→ 路由器发现任一台即视为发现该人 → 找回/撤销 → 结案。case 状态机 + 页面（`cases.py` + `case.html`，2026-09-11 完成）。多设备定位聚合并入「真实 report 聚合」。
- [x] **审计日志**：走失标记、撤销、重放、超窗、验签失败的持久化审计（谁/何时/哪个 SN/前后状态/结果）+ **数据保留期限/最小化**意识。→ **已做一半**（2026-09-11）：所有业务事件落 IoTDB `root.orpah.events`（`publish`/`found`/`id_report`/`case_mark`/`case_found`/`case_close`），`/api/ts/events` 可回读、`index.html` 有「事件历史」区，**重启后仍在**。**未做**：审计里的「谁」（操作者/角色）、数据保留期限、超出演示的完整覆盖面。
- [ ] **告警与通知**：RSSI 突变、长未上报、校验位连续失败、签名失败率超阈、走失超时 → 规则引擎 + 通知（页面红点/Webhook/邮件；演示可用 SSE 弹窗）。
- [ ] **回放**：按时间段回放报文流 + 定位轨迹 + 安全事件。
- [ ] **重放/篡改自动化测试台**：批量用例（黄金样本、边界 SN、过期 nonce、错 CC）一键跑并出报告。

## 四、传输与真机适配

- [ ] **无认证空口防 spoof 端到端演示（P1）**：开放空口 + 伪造 report 被拒 vs 合法签名 report 通过（结合 Damm32 + 签名）。
- [ ] **Wi-Fi 抓包 → ORPAH 报文解析** 与 **HaLow/UDP 模拟器**双源对照。
- [ ] **多租户/多组织**：SN 按组织隔离、角色权限（看客/运维/管理员）。
- [ ] **时钟可信**：无 RTC 设备的 ts 处理（协议 ts=0 跳过窗口）在定位与审计中的一致性。

## 七、第三方素材与许可（2026-09-11 核实）

| 素材 | 位置 | 许可 | 义务 / 风险 |
|---|---|---|---|
| **Leaflet 1.9.4** | `ui/static/vendor/leaflet/`（已入库） | **BSD-2-Clause** | 保留版权与许可文本（已附 `LICENSE-leaflet.txt`）；可商用、无 copyleft |
| 底图瓦片 | 运行时外部请求，**不入库** | 各源不同 | 见 `track.html` 的 `TILE_PROVIDERS`；页面上选了哪个源就显示对应条款提示 |

**底图要点（选型时必读）**：

- `tile.openstreetmap.org`（默认）受独立的 [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) 约束：
  必须**可见署名**、必须**可识别 UA**（网页场景浏览器默认 UA 可接受）、必须**遵守缓存头**（≥7 天）；
  **禁止**批量下载 / 预取 / 离线打包 / 高倍自动扫图；**无 SLA，可无预警封禁**。
- **OpenTopoMap** = CC-BY-SA 3.0：可商用、免许可费；需按官方文本署名
  （`Map data: © OpenStreetMap contributors, SRTM | Map style: © OpenTopoMap (CC-BY-SA)`，
  不能简写），且衍生作品需相同方式共享。
- **CARTO / Esri**：商业服务商，生产使用前需单独确认条款（可能需账号/付费）。
- **结论**：本库演示用法（网页内嵌 + attribution 控件 + 可自定义源）合规；
  但**产品化与离线场景不得依赖 OSM 官方瓦片**。
