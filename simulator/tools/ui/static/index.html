启动模拟器

  

    常用启动命令（点击展开）
    

      
python server.py --a pc:txah --b pc:txah两台 TX-AH 虚拟机（泰芯 TX-AH-MODULE，无硬件）

      
python server.py --a COM3:txah --b pc:txah一台 TX-AH 真机 + 虚拟机（两者不互通）

      
python server.py --a COM3:txah --b COM4:txah两台 TX-AH 真机（真实 RF 互联）

      
python server.py --host-sim --target tj45两台 T-Halow-RJ45 虚拟机（LilyGo，无硬件）

      
python server.py --a COM3:tj45 --b COM4:tj45两台 T-Halow-RJ45 真机（固件代次 V1.6/V2.4 自动探测，真实 RF）

      
python server.py --a COM3:tj45 --b COM4:txahTH-RJ45 + TX-AH 真机（TH-RJ45 升 V2.4 也能自动识别，同代互联）

      
python server.py --host-sim --target hc01两台 HT-HC01 虚拟机（惠特自动化 ESP32+MM6108 · 占位，无硬件）

      
python server.py --a COM3:hc01 --b COM4:hc01两台 HT-HC01 真机（真实 RF）

      
python server.py --list列出本机串口
